# Что такое idryer-core

`idryer-core` — C++ библиотека для Arduino/ESP-IDF, которая предоставляет общий платформенный слой для всех ESP32-устройств iDryer. Библиотека управляет подключением к облаку, MQTT-обменом и маршрутизацией команд. Продукт реализует только специфичное для него поведение.

## Что библиотека делает

- Подключается к WiFi и удерживает соединение.
- Проходит provisioning (регистрация устройства в бэкенде) и claiming (привязка к аккаунту пользователя).
- Устанавливает и поддерживает MQTT-сессию с брокером iDryer (TLS, persistent session).
- Маршрутизирует входящие команды (`commands/invoke`, `commands/set`, `commands/ping`) к нужному обработчику.
- Предоставляет UART-бридж для двухпроцессорных устройств (ESP32 + RP2040).
- Содержит клиенты сторонних интеграций: Bambu Lab LAN, Home Assistant MQTT, Moonraker/Klipper WebSocket.

## Что библиотека не делает

- Не управляет железом продукта (вентиляторами, нагревателями, LED-лентами, датчиками).
- Не знает о конкретных конфигурационных параметрах продукта — только транспортирует их.
- Не публикует телеметрию автоматически — продукт сам решает когда и что публиковать.
- Не содержит бизнес-логики сушки или хранения.

## Кто использует библиотеку

Каждый ESP32-продукт iDryer включает `idryer-core` как зависимость PlatformIO и собирает нужные объекты в своём `main.cpp`.

Примеры продуктов:

- **iDryer Storage** — ESP32-C3, управляет LED-лентой, опциональный датчик SHT31.
- **iDryer LINK** — ESP32, шлюз между RP2040-контроллером сушилки и облаком.
- **iHeater LINK** — ESP32, шлюз для iHeater с поддержкой Moonraker/Bambu.

## Зависимости

Библиотека зависит от:

- `PubSubClient` — MQTT-транспорт.
- `ArduinoJson` — сериализация/десериализация JSON.
- `WiFi` / `WiFiClientSecure` — WiFi и TLS.
- `Preferences` — NVS для хранения credentials и конфигурации.
- `WebSocketsClient` — WebSocket для Moonraker-интеграции.

Библиотека не тянет FastLED, Wire, ImprovWiFi и другие продуктовые зависимости.
