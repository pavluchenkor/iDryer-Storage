# UART: физический уровень

Описание электрической части связи между MCU и LINK. Если вы собираете плату — начните отсюда.

!!! note "Контекст"
    Термины и роли MCU/LINK — в [../01-overview/03-nodes-and-roles.md](../01-overview/03-nodes-and-roles.md). Быстрый пример с кодом — [../02-getting-started/02-quickstart-controller.md](../02-getting-started/02-quickstart-controller.md).

---

## Параметры связи

| Параметр | Значение |
|----------|----------|
| Скорость (baud rate) | **115200** |
| Формат кадра UART | **8N1** (8 бит данных, без чётности, 1 стоп-бит) |
| Аппаратный контроль потока | **не используется** (RTS/CTS не нужны) |
| Направление | полный дуплекс (обе стороны шлют одновременно) |
| Уровни | **3.3 В логические** (соответствует выходам ESP32) |

Значения 115200/8N1 жёстко заданы в обеих прошивках. Изменение требует пересборки и MCU, и LINK — контракт зафиксирован в `src/uart/uart_protocol.h` и подтверждён в `uart_bridge.cpp`.

!!! warning "Уровни 5 В"
    Если ваш MCU работает на 5 В (классический Arduino Uno/Mega на ATmega328), вход ESP32 не терпит 5 В — сожжёте пин. Используйте **двунаправленный level-shifter** (TXS0108, BSS138 + подтяжки) или делитель напряжения на TX → RX ESP32.

## Схема подключения

```
           MCU (3.3 В)           LINK (ESP32, 3.3 В)
          ┌────────┐            ┌──────────┐
          │   TX   ├────────────┤   RX     │    линия передачи MCU→LINK
          │   RX   ├────────────┤   TX     │    линия передачи LINK→MCU
          │   GND  ├────────────┤   GND    │    общая земля (обязательна)
          └────────┘            └──────────┘
```

Питание двух плат может быть независимым (каждая от своего источника), но **общая земля обязательна**. Без неё передача либо вовсе не пойдёт, либо будет прерываться случайно.

### Если MCU пятивольтовый

```
       Arduino Mega (5 В)         ESP32 (3.3 В)
         ┌─────────┐             ┌─────────┐
         │ TX pin18├──┬────────┬─┤   RX    │
         │         │  │Level-  │ │         │
         │ RX pin19├──┤shifter ├─┤   TX    │
         │    GND  ├──┤(2-ch)  ├─┤   GND   │
         └─────────┘  └────────┘ └─────────┘
                         │
                      GND обеих сторон
```

Альтернатива для TX MCU → RX ESP32 (только одно направление): простой делитель `1 kΩ + 2 kΩ` на землю.

## Требования к качеству сигнала

- Длина линии — до ~30 см на обычной «гребёнке» проводов. Длиннее — витая пара или экранированный кабель, возможно снижение скорости.
- Никаких конденсаторов по линии данных — поднимут фронты, собьют битрейт.
- Если провода идут рядом с шумным питанием нагревателей — добавьте подтяжку `10 kΩ` к VCC на обеих линиях RX. Это не обязательно, но помогает против наведённых помех.

## Первый запуск: что проверить

Перед тем как отлаживать протокол, убедитесь, что физика работает:

1. **Цоколёвка:** `MCU TX ↔ LINK RX` (crossover). Частая ошибка — соединить TX↔TX.
2. **Общая земля:** обязательна, даже если питание общее.
3. **Скорость:** обе стороны на 115200. Многие библиотеки по умолчанию 9600.
4. **UART-порт:** `Serial` обычно занят USB-дебагом; для связи между платами берут `Serial1`/`Serial2`. См. таблицу пинов в [../02-getting-started/02-quickstart-controller.md](../02-getting-started/02-quickstart-controller.md).

Если с физикой всё хорошо, на любом терминале (Hercules, `screen`, `minicom`) после отправки кадра вы увидите `0xAA …` с другой стороны — **не обязательно** целиком корректный кадр, но именно эти байты.
