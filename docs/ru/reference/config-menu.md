# Конфигурационное меню Storage Link

Источник истины для меню — [`lib/idryer-menu/menu_v2.yaml`](../../../lib/idryer-menu/menu_v2.yaml).
Числовые ID берутся из автогенерированного [`lib/idryer-menu/src/menu_ids.h`](../../../lib/idryer-menu/src/menu_ids.h).

## Актуальные пункты

| ID | Bind | Тип | Диапазон / варианты | Default | Применение |
|----|------|-----|---------------------|---------|------------|
| `2` | `led_count` | value | `1..300`, шаг `1` | `120` | применяется сразу |
| `3` | `psu_ma` | value | `500..20000`, шаг `100` | `5000` | применяется сразу |
| `5` | `strip_ws2812b` | toggle | `0/1` | `true` | требует reboot |
| `6` | `strip_apa102` | toggle | `0/1` | `false` | требует reboot |
| `8` | `order_grb` | toggle | `0/1` | `true` | требует reboot |
| `9` | `order_rgb` | toggle | `0/1` | `false` | требует reboot |
| `10` | `order_brg` | toggle | `0/1` | `false` | требует reboot |
| `11` | `order_bgr` | toggle | `0/1` | `false` | требует reboot |
| `13` | `language` | value | `0=ru`, `1=en` | `1` | отражается в `config` |

`units_count` тоже присутствует в YAML, но в текущем продукте зафиксирован на `1` и не является пользовательской настройкой поведения.

## Формат `config`

По запросу устройство возвращает:

```json
{
  "v": 1,
  "units": 1,
  "active": 0,
  "lang": "en",
  "deviceType": "storage_link",
  "menu": [
    { "id": 2, "t": "val", "val": 120 },
    { "id": 3, "t": "val", "val": 5000 },
    { "id": 5, "t": "toggle", "val": true }
  ]
}
```

Формирование происходит в [`LedStripProfile::getConfig()`](../../../src/storage/led_strip/led_strip_profile.cpp).

## Семантика toggle-групп

Для типа ленты и порядка цветов действует правило "ровно один активный пункт".

Это означает:

- `set` с `val = 1` на выбранный пункт активирует его и выключает остальные в той же группе;
- `set` с `val = 0` для этих пунктов не используется как отдельная операция выключения;
- при повреждённом состоянии NVS прошивка нормализует группу на старте.

## Практический смысл для клиента

Если UI меняет тип ленты или порядок цветов, надо:

1. отправить `commands/set`;
2. показать пользователю, что изменение сохранено;
3. отдельно попросить сделать reboot устройства, иначе FastLED останется в старой конфигурации.
