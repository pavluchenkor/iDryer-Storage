# Changelog

Русская версия журнала. Основная — [CHANGELOG.md](CHANGELOG.md). Здесь фиксируются заметные изменения в прошивке `iDryer-Storage` — шкафа хранения филамента.

## Типы изменений

- **Добавлено** — для новых функций.
- **Изменено** — для изменений в существующей функциональности.
- **Устарело** — для функций, которые скоро будут удалены.
- **Удалено** — для удалённых на данный момент функций.
- **Исправлено** — для любых исправлений багов.
- **Безопасность** — на случай уязвимостей.

## [3.0.0] — 2026-09-23

### Добавлено

- **Обновление прошивки по воздуху.** Шкаф обновляется с портала сам.
- **Привязка к порталу без PIN.** Устройство получает ключ при подключении и адресуется в облаке по собственному идентификатору.
- **Отвязка из портала.** Команда с портала стирает ключ, устройство возвращается в режим ожидания привязки.
- **Управление по локальной сети.** Приложение работает со шкафом напрямую в той же сети, без облака.
- **Действия карточки в портале и приложении.** Шкаф объявляет, что умеет, и интерфейс рисуется по этой декларации: включить свет с выбранным эффектом и цветом, выключить.
- **Home Assistant из card-манифеста.** Шкаф появляется в Home Assistant с показаниями и органами управления; сущности строятся из той же декларации.
- **Анимации светодиодной ленты.** Десять эффектов, выбираются на устройстве и из карточки: цвет, дыхание, волна, радуга, мерцание, переливы, прилив, рябь, прожектор и два цвета.
- **Разметка флеша без файловой системы.** Под прошивку два раздела по 1 984 КБ вместо 1 280 КБ: файловую систему прошивка не использует.

### Изменено

- Прошивка переведена на общую библиотеку `idryer-core`: связь с порталом, привязка и протокол одинаковы для всех устройств экосистемы.
- **В образ собирается только Home Assistant.** Шкаф с принтерами не общается, поэтому Bambu Lab и Moonraker в образ не попадают — он стал легче на 36 КБ.
- **Прибор объявляет свои интеграции.** Портал и приложение рисуют только то, что у шкафа действительно есть.
- Периоды публикации телеметрии и статуса приходят из контракта.

### Удалено

- Пять шумовых анимаций — сияние, свеча, океан, лава и лес. Они занимали 3,7 КБ флеша, который был нужен шкафу под другое; код сохранён закомментированным рядом с остальными эффектами.
